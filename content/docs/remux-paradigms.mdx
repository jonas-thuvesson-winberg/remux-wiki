Remux is an extensible media platform built around addons, tasks, and configurable content collections. This guide walks through core concepts — Addons, Tasks, Content, IPTV, and Streaming — and how they work together.

## A. Addons

Remux ships with the **TMDB Addon** enabled by default. All additional functionality is added through addons.

![Addons overview](/addons-overview.png)

Select the addons that provide the functionality you'd like to add to Remux, then click **Configure** to set them up.

![Addon configuration](/addon-configuration.png)

> **Note — Priority Ranking**
> Addons follow a priority ranking system, ordered top to bottom. If you want search results and catalogs from one addon to take priority over another, reorder the addons and give your preferred addon higher priority.

![Addon order](/addon_order.png)

## B. Tasks

Once functionality has been added via Addons, the **Tasks** section is where those functions are enabled and run.

**For example, after creating libraries or adding IPTV playlists, you must run the corresponding task for that content to appear. Tasks can also be scheduled to run automatically.**

![Tasks overview](/tasks-overview.png)

## C. Content

Remux's content model is built around **infinitely extensible Collections**, sourced from addons and displayed in a variety of ways.

You can import lists from **AIOStreams**, **AIOMetadata**, or most Stremio-compatible `manifest.json` sources via the Addons section, then add them to any available library type.

> If you encounter a Stremio-compatible manifest that isn't supported, please report it as an issue.

![Content collections](/content-collections.png)

**Note:** Collections with the **"Promote to Library"** toggle enabled are displayed as individual libraries and rows in the Web UI. The order in which these appear is managed under **User Settings → Home**.

## D. IPTV

The IPTV workflow follows three steps:

1. **Add the IPTV source** via Addons (M3U and Xtream types are supported).
2. **Run the IPTV Task** to import the playlist into Remux.
3. **Enable channels** you want populated in the UI, under **Content → IPTV**.

![IPTV channel management](/iptv-channel-management.png)

## E. Streaming

> **Note:** Stream sort order and name formatting are configured in **AIOStreams**.

Remux adds the ability to further **group** stream results. Streams can be filtered and grouped by:

- Resolution
- Codec
- Quality
- Size
- Audio Language

![Stream grouping options](/stream-grouping-options.png)

**Note:** When Stream Groups are enabled and configured, the name formatting set in AIOStreams will be overridden.

### Stream Probing & Fallback

Stream probing duration and fallback behavior are configured in the **Probing** section.

It's recommended to enable **Auto Next Stream** when using Stream Groups — this ensures another stream is automatically attempted if playback fails or stalls. You can also configure the maximum number of streams in the fallback queue.

![Probing settings](/probing-settings.png)
