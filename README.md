# Remux Wiki

The Remux documentation site, built with [Fumapress](https://press.fumadocs.dev/).

## Development

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

The site is available at `http://localhost:3000`.

## Checks

```bash
npm run lint
npm run types:check
npm run build
```

Wiki pages live in `content/docs`.
